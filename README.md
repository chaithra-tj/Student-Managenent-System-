Student Management System

Project Description

The Student Management System is a beginner-friendly Python project that helps manage student records. It allows users to add, view, search, update, and delete student details.

Technologies Used

- Python
- JSON
- VS Code

Features

- Add new student records
- View all student records
- Search students using Student ID
- Update student details
- Delete student records
- Store student data using a JSON file
- Input validation

Project Structure

Student_Management_System/
│
├── student.py
├── students.json
└── README.md

How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:

python student.py

- File handling
- JSON data storage
